# Studio X authentication security

NextAuth v4 credentials provider is selected for compatibility with Next.js 15 App Router. Passwords use bcryptjs cost 12 (pure JavaScript, compatible with Vercel). Sessions use signed JWT cookies (httpOnly, sameSite=lax, secure under production Node environment), maximum 8 hours. Middleware is a navigation redirect only; every API admin handler must call requireUser or requireRole and reload the current user from PostgreSQL. Locked, inactive or role-changed accounts are rejected server-side. Login uses one generic error, email normalization, failed-login lockout after five attempts for 15 minutes, hashed identifiers in audit logs, and a database-backed atomic rate limiter for deployed environments. The in-memory limiter is development-only.

Owner provisioning is dev-only, requires DB_TARGET=dev, a pinned dev Neon endpoint, OWNER_EMAIL and OWNER_PASSWORD (12+ characters), refuses duplicate OWNER records, and logs no credentials. Do not trigger until secrets are confirmed. The admin owner-test route and owner-test API are test-only and must be removed in the admin product phase. A full production security review is required before launch.
