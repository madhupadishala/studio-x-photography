# Provider verification log

No live Meta, WhatsApp, Instagram or YouTube account has been authorized in this repository yet. The following items remain disabled until verified against current official provider documentation and a test business account:

- WhatsApp Cloud API template names, language codes, message-window and pricing rules.
- Instagram webhook payload shape, private-reply endpoint, eligibility and app-review permissions.
- YouTube channel/analytics scopes and CTA link behavior.
- Provider token rotation, expiry, data retention and deletion behavior.

Record date, official source URL, observed behavior, test account and reviewer for each verification. Do not use browser-session automation or scrape social platforms.
